# Onboarding Path

What a new engineer does in the first week.

## Day One

Accounts, laptop, and access requests. The checklist is in the wiki and takes
about two hours.

## Day Two

Local environment setup. The bootstrap script installs everything the service
needs to run in development mode.

## Day Three

First pull request: a small fix with a test, reviewed within the day.

## Week One Wrap-Up

| Milestone | Owner | Done when |
| --- | --- | --- |
| accounts | IT | all systems reachable |
| dev env | mentor | service runs locally |
| first PR | buddy | merged to main |
| on-call shadow | team | one incident observed |

## After Onboarding

The new engineer joins the rotation as a shadow, then a secondary, then a
primary within one quarter.
